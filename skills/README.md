# Skills kurzu „AI v datové analýze"

Pět postupů z kurzu zapsaných ve formátu [Agent Skills](https://agentskills.io) (`SKILL.md`) —
otevřený standard, kterému rozumí ChatGPT, Claude, Claude Code, Codex, VS Code, Gemini CLI
a desítky dalších nástrojů. Nahrajte složku skillu do svého nástroje (nebo ji přiložte
do konverzace) a AI postup použije, kdykoli se hodí.

| Skill | Kdy se hodí |
|---|---|
| `clarify-analysis-brief` | Vágní zadání od businessu → strukturovaný analytický plán |
| `eda-profiler` | Nový dataset → posouzení kvality před analýzou |
| `data-transformer` | Špinavá data + agent → vyčištěná data s logem změn |
| `extract-and-evaluate` | Nestrukturovaný text → strukturovaná data se změřenou chybovostí |
| `summarize-for-management` | Hotová analýza → shrnutí pro vedení s dohledatelnými čísly |

Skilly jsou záměrně stručné — upravte si je podle vlastní zkušenosti. Nejlepší skill je ten,
který jste si sami vyladili.
